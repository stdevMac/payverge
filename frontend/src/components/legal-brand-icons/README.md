# Legal brand icons

Third-party brand colors (Google blue, Telegram blue, WhatsApp green, Meta blue)
may be used literally *only* in components kept in this directory. Each such
component must include a top-of-file `/* eslint-disable no-restricted-syntax */`
and a comment explaining which third-party brand it represents.

This is an allowlist, not a loophole — if a component does not represent a
third-party logo, it does not belong here.
