# Menu tab

- Add **categories** first, then **items** inside each category.
- Use **Menu Builder** for prices, descriptions, dietary tags, and photos.
- **AI menu builder** (wizard) can draft categories/items from a photo or description.
- **Hide / 86** an item from the item drawer without deleting it.
- Preview the guest-facing page from **Business Page** settings.

Common intents: add item, change price, hide item, categories, AI menu.
