# Overview tab

- **OnboardingHub** shows setup progress (profile, tables, menu, staff, payment).
- KPI cards summarize today's revenue, open bills, and reservations — hover for definitions.
- **Pre-Shift briefing** lives under Director Console when an LLM provider is configured; Ops Assistant handles day-to-day navigation.
- Use Overview to spot incomplete setup before going live.

Common intents: "What do these numbers mean?", "Where is onboarding?", "Why is my dashboard empty?"
